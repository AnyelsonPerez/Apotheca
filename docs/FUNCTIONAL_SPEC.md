# Functional Specification

## Casos de uso
### UC1 Buscar medicamento
Buscar por nombre, principio activo, CN o código de barras.

### UC2 Agregar medicamento
Consulta CIMA, precarga ficha y permite completar:
- cantidad (opcional)
- caducidad (opcional)
- posología (opcional)

### UC3 Principio activo existente
Advertencia si existe un medicamento con el mismo principio activo.

### UC4 Caducidad
Avisos globales configurables.

### UC5 Agotamiento
Cálculo basado en cantidad y dosis diaria.
