# Apotheca

Apotheca es una solución self-hosted para la gestión doméstica de medicamentos.

## Características MVP
- Inventario familiar compartido
- Integración con CIMA (AEMPS)
- Búsqueda por nombre comercial, principio activo, CN y código de barras
- Gestión por lotes
- Alertas de caducidad
- Alertas de agotamiento estimado
- Android (React Native)
- Web (React)
- API (FastAPI)
- SQLite
- Docker
- Instalación Proxmox
- Backup y Restore
- Distribución de APK desde la propia instancia
